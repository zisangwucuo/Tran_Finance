# 材料提取 v3

本次针对两个不同问题修复：扫描PDF缺少文字层，以及AI返回JSON包装结构不兼容。

## 本机OCR

Windows 后端调用系统自带 Windows PowerShell 5.1 和简体中文 OCR。
不需要新增 Python 包或把图片发送给视觉模型。文字少于20字符的页面会先渲染为图片，
在本机识别，再进入原有文字提取流程。每页最长等待60秒；多页扫描报告可能需要数分钟。
临时脚本、图片和文字文件均按明确路径逐个清理，不打印材料内容。

其他电脑必须安装 Windows 简体中文 OCR 语言功能；Linux/macOS 不走此通道，
仍需提供带文字层的 PDF。本机识别并不保证数字、表格列、单位识别正确，采用前必须核对原页。

## AI事实抽取

逐页抽取，每页提示最多12条明确的量化事实。接受 candidates 对象、顶层数组、
data.candidates 包装；不根据缺少的字段推测数值。单页失败保留其他成功页，连续三页失败则停止。
任务诊断显示失败页及经过清洗的错误原因。成功页结果不等同于整份报告完整覆盖。

从其他公司的报告中提取出的事实可以展示，但主体、年份或口径不符时仍不能写入当前企业记录。
旧任务不会自动重新解析，需要重启更新后的后端并重新上传。

## 验证边界

真实扫描件 1223097316.pdf 的物理第20页已通过本机OCR单页测试。
AI包装格式与证据校验使用自动化测试验证；在线AI返回有效事实还取决于运行时配置、权限和模型能力，
不能把本机OCR成功当作在线AI端到端成功。
