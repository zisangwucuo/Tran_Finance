# 企业材料提取演示版

## 启动与配置

后端新增 Apache PDFBox 3.0.5，Maven自动安装，Python模型服务无需新增依赖。
重启后端后，退出并重新登录企业账号，使新材料接口建立服务端企业会话。
企业端入口：材料上传与指标提取。首版支持钢铁、基础化工行业。

复用现有 `ai.narrative` 配置及环境变量：`AI_NARRATIVE_ENABLED`、
`AI_NARRATIVE_API_URL`、`AI_NARRATIVE_API_KEY`、`AI_NARRATIVE_MODEL`。
可选 `AI_NARRATIVE_RESPONSE_FORMAT_JSON`、`AI_NARRATIVE_DEEPSEEK_THINKING_DISABLED`。
不把密钥写入源码、文档或截图。AI未配置或调用失败会明确失败，不生成假数据。

任务表与采用审计表在首次使用时自动创建；无建表权限的部署可单独运行
`database/20261109_material_extraction.sql`，不要重跑完整数据库初始化文件。
PDF默认保存在项目 `.runtime/materials`，已加入Git忽略。
部署可用 `MATERIALS_STORAGE_DIR` 指定独立目录；迁移时同时备份材料目录和数据库。

## 演示操作

1. 登录对应企业，选择报告的真实数据年份，上传100MB以内、500页以内的文字型PDF。
2. 勾选向已配置AI服务发送相关片段的同意项，点击开始提取。
3. 任务进度显示解析、AI提取与核验、完成或失败。刷新后可重新选中任务继续查看。
4. 查看指标、候选值、单位、年份及核验状态，打开依据弹窗查看物理PDF页码和连续原文。
5. 查看评价模板，展示分子、分母、标准单位和口径版本。
6. 提取结果会独立保存；如需入库，勾选候选并点击“写入待评估数据（可选）”，选择本企业同年度的一条待评估记录。
7. 对比原值和采用值，填写复核说明，确认企业主体、期间和核算范围后写入。
8. 金融机构重新打开该记录可见更新；旧转型评分清空，需重新评估。

采用只修改所选记录，银行间不自动同步。不覆盖历史记录、不自动授信。
同一材料任务对同一记录只能确认采用一次，所有选定指标应一次提交。
并发修改时要求刷新；记录已授信归档或不属于该企业时拒绝写入。
采用审计保留原值、新值、页码、证据和复核说明；本版本未接入旧“补全通知”页面。

## 适合PPT的真实案例

宝钢2024年报告（1223329096.pdf）物理PDF第40页可提取2.00吨二氧化碳/吨粗钢，
原文核算边界为四基地。可展示数值、年份、分母与边界的分离提取。
必须登录与材料主体对应的企业；如无对应年度待评估记录，只展示结果，不向其他企业写入。
化工模板复用相同流程，替换专项指标及单位定义，展示行业适配。

## 能力边界

这是人工配置元模型驱动的AI提取原型，不是自动政策建模或官方标准认证。
模板来源暂为项目指标目录及演示口径，正式应用需审核政策出处、排放范围与公式。
每个指标相关页面与通用量化披露页面共同检索，优先数字密集的页面。
最多24页、总片段上限96000字符，单页上限6000字符，每四页一批调用AI。
界面保留实际送审页数；未找到仅代表所检索片段未找到，不代表全文没有或取值为0。
扫描/图像页无文字层时提示OCR，首版不做OCR，不保证跨页表格抽取。
多候选冲突、年份不符、原文不匹配、单位/粗钢分母不符不能直接采用。
未做自动数值计算或单位换算；候选不能在前端随意改为无证据数字。
核算边界通常要求人工复核，不以模型置信度代替事实核查。
任务队列为单实例本地线程池，两个任务并行；服务重启中断任务标为失败，可重新上传。

`mvn test -Dmaterial.sample=C:/Users/Administrator/Desktop/1223329096.pdf`。

## 独立更换材料提取API

默认复用报告AI。可在后端进程环境中设置以下变量单独覆盖，重启后端生效：
`MATERIAL_AI_ENABLED=true`、`MATERIAL_AI_API_URL`（完整chat/completions地址）、
`MATERIAL_AI_API_KEY`、`MATERIAL_AI_MODEL`。
可选 `MATERIAL_AI_THINKING_DISABLED`、`MATERIAL_AI_RESPONSE_FORMAT_JSON`。
需要兼容Chat Completions接口。仅在当前配置支持时启用thinking参数。
不要将真实密钥写进仓库。更换API不会重算已有任务，需要重新上传提取。

任务“未提取到候选值”表示本次AI请求返回了有效结构，但没有匹配模板的候选；
不表示API认证失败，也不证明模型提取质量正确。应先核对行业、年份及送审页。
例如1223309920.pdf为2024年化工报告，不能按2025年钢铁模板评价。

## v2：先抽取事实，再匹配模板

提取提示不传入企业模板、企业身份或目标年份，保留原文指标名称、原值、年份、主体、分母和数值性质。
本地规则随后匹配模板；模板外指标、其他年份与目标值保留展示，不能直接采用。
主营业务收入与营业收入等明确分母差异会阻止采用，而不是丢弃原始事实。
报告主体与登录企业名称不一致时仅展示，不能靠勾选确认跨企业写入。
企业简称尚无自动验证机制，因此名称未核实也会拦截，需使用准确材料。

“已提取指标”与“模板待补项”分开显示；诊断弹窗展示实际送审页、事实清单及AI结构化响应。
结构化响应保存在原任务result_json内，仅所属企业会话可读，不打印到日志。
分批失败保留成功批次，任务标记失败而不是部分成功，不能入库。
旧任务不自动重算，也无法补回未保存的AI响应；需重新上传生成v2任务。
仍为文字提取，不发送页面图片，不包含OCR或视觉模型调用。
新增回归测试MaterialFactPipelineTest验证事实保留和写入拦截。
可选真实AI测试需显式指定 `-Dmaterial.live=true -Dmaterial.live.pdf=报告绝对路径`
并运行MaterialLiveExtractionTest；该测试仅发送第12页，不改数据库，缺少有效配置时会跳过。
